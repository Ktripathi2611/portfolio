### 4.3 Source Code Directories

#### 📁 `src/app/` — Pages & Routing (Next.js App Router)

This directory follows Next.js file-based routing. Each subfolder with a `page.tsx` creates a URL route.

| Route                | File                                | Description                            |
| -------------------- | ----------------------------------- | -------------------------------------- |
| `/`                  | `app/page.tsx`                      | Homepage — hero section, globe, stats  |
| `/about`             | `app/about/page.tsx`                | Developer bio, skills, and info        |
| `/projects`          | `app/projects/page.tsx`             | Project cards gallery                  |
| `/experience`        | `app/experience/page.tsx`           | Work experience timeline               |
| `/contact`           | `app/contact/page.tsx`              | Contact form and information           |
| `/github-activity`   | `app/github-activity/page.tsx`      | GitHub contribution dashboard          |
| `/api/github/activity` | `app/api/github/activity/route.ts` | API — fetches GitHub stats             |
| `/api/github/refresh`  | `app/api/github/refresh/route.ts`  | API — refreshes GitHub data cache      |

**Key Files:**
- `layout.tsx` — Root layout loaded on every page. Sets up fonts (Inter + Space Grotesk), navbar, footer, scroll progress bar, AI orb, behavior tracking, immersive effects, debug panel, JSON-LD schema, and Vercel Analytics.
- `globals.css` — 363-line design system with CSS custom properties for fluid spacing, fluid typography, glassmorphism, gradient text, button styles, grid utilities, scrollbar, page transitions, and animations.

**Dependencies:** Layout uses components from `components/layout/`, `components/ai/`, `components/immersive/`, `components/debug/`, and `components/ui/`. Pages use data from `data/`.

## 5. Step-by-Step Website Creation

### Step 1: Install Node.js

1. Go to: [https://nodejs.org](https://nodejs.org)
2. Download and install **Node.js version 18+** (LTS recommended)
3. Verify installation:

```bash
node -v
# Expected output: v18.x.x or higher

npm -v
# Expected output: 9.x.x or higher
```

### Step 2: Clone the Repository

```bash
# Clone the project
git clone https://github.com/Ktripathi2611/portfolio.git

# Navigate into the project folder
cd portfolio

# Install all dependencies
npm install
```

> This will read `package.json` and install all 12 production dependencies and 8 dev dependencies into `node_modules/`.

### Step 3: Understanding the CSS / Design System

The styling is handled through **two key files**:

**`tailwind.config.ts`** — Defines the custom design tokens:
- **Colors:** Deep charcoal background (`#0a0a0f`), neon blue (`#00d4ff`), purple (`#a855f7`), pink (`#ec4899`)
- **Fonts:** Inter (body text), Space Grotesk (headings/display)
- **Animations:** Float, glow, gradient shift, pulse-slow, spin-slow
- **Glassmorphism:** Custom glass card backgrounds with backdrop blur
- **Shadows:** Glow effects in blue and purple variants

**`src/app/globals.css`** — Global design system with:
- Fluid spacing scale (`--space-xs` to `--space-3xl`) using CSS `clamp()`
- Fluid typography scale (`--text-xs` to `--text-hero`)
- Reusable CSS classes: `.glass-card`, `.btn-primary`, `.btn-secondary`, `.gradient-text`
- Layout utilities: `.container`, `.section`, `.stack`, `.grid-auto`
- Custom scrollbar with gradient colors
- Page transition animations

**No separate `style.css` file is needed** — Tailwind CSS utility classes + `globals.css` handle all styling.

### Step 4: How to Add / Update Content

#### 📝 Update Projects

Edit `src/data/projects.ts`:

```typescript
{
    id: "my-project",
    title: "My New Project",
    description: "Short description for card view.",
    longDescription: "Detailed description of the project.",
    technologies: ["Python", "Django", "React"],
    githubUrl: "https://github.com/username/repo",
    liveUrl: "https://myproject.com",
    image: "/images/projects/my-project.jpg",
    featured: true,
}
```

#### 👤 Update Experience

Edit `src/data/experience.ts`:

```typescript
{
    id: "exp-new",
    title: "Software Engineer",
    company: "Company Name",
    location: "City, Country",
    period: "2024 - Present",
    description: "Role description.",
    achievements: [
        "Achievement 1",
        "Achievement 2",
    ],
    technologies: ["Python", "FastAPI", "PostgreSQL"],
}
```

#### 🛠 Update Skills

Edit `src/data/skills.ts`:

```typescript
{ name: "New Skill", level: 85, category: "backend" }
// Categories: "backend" | "frontend" | "database" | "devops" | "tools"
// Level: 0-100 (proficiency percentage)
```

#### 🖼️ Add Images

1. Place project images in `public/images/projects/`
2. Reference them as `/images/projects/filename.jpg` in the data files
3. Next.js `next/image` optimizes them automatically

## 8. How to Deploy on Hosting (Vercel)

### Vercel Deployment Steps

1. Go to [https://vercel.com](https://vercel.com)
2. Click **Login** → Sign in with GitHub
3. Click **Add New → Project**
4. Select your `portfolio` repository from the list
5. Vercel auto-detects it as a Next.js project
6. Click **Deploy**

**Vercel will automatically:**
- ✅ Install all dependencies (`npm install`)
- ✅ Build the project (`npm run build`)
- ✅ Generate sitemap and robots.txt
- ✅ Deploy to a global CDN

### After Deployment

You will receive a **live URL** like:

```
https://portfolio-username.vercel.app
```

### Custom Domain Setup (Optional)

1. In Vercel dashboard → **Settings → Domains**
2. Add your domain (e.g., `kushaltripathi.dev`)
3. Update DNS records at your domain registrar:
   - **A Record:** `76.76.21.21`
   - **CNAME Record:** `cname.vercel-dns.com`

### Google Search Console Setup

1. Go to [Google Search Console](https://search.google.com/search-console)
2. Add property with your domain
3. Verify ownership (the `googlef5fbbb4a7aabfa16.html` file in `public/` handles this)
4. Submit sitemap URL: `https://yourdomain.com/sitemap.xml`

| `'npm' is not recognized`      | Node.js not installed            | Install Node.js from [nodejs.org](https://nodejs.org) |
| `Module not found`             | Dependencies not installed       | Run `npm install`                              |
| `Port 3000 already in use`     | Another app using port 3000      | Stop the other app, or run `npm run dev -- --port 3001` |
| `Build failed`                 | Code/syntax error                | Check terminal output for the exact error line |
| `ENOENT: no such file`         | Missing file referenced in code  | Ensure all referenced files exist              |
| `Three.js / WebGL errors`      | GPU/driver compatibility issue   | Update GPU drivers; works best on Chrome       |
| `TypeError: Cannot read property` | Null/undefined data           | Check your data files in `src/data/`           |
| `hydration mismatch`           | Server/client HTML mismatch      | Ensure dynamic imports use `ssr: false` for 3D |
| `GITHUB_TOKEN not set`         | Missing environment variable     | Create `.env.local` with `GITHUB_TOKEN=...`    |

### Environment Variables

## 13. Contributing & Best Practices

### Project Conventions

| Convention            | Standard                                                     |
| --------------------- | ------------------------------------------------------------ |
| **File Naming**       | PascalCase for components (`HeroSection.tsx`), camelCase for utils (`animations.ts`) |
| **Component Style**   | Functional components with TypeScript + React hooks           |
| **Styling**           | Tailwind CSS utilities + custom CSS classes from `globals.css` |
| **Path Aliases**      | Use `@/` prefix instead of relative paths (e.g., `@/components/ui/GlassCard`) |
| **Dynamic Imports**   | Use `next/dynamic` with `ssr: false` for Three.js / WebGL components |
| **Data Management**   | All content in `src/data/` — no hardcoded strings in components |

### Adding a New Page

1. Create folder in `src/app/` (e.g., `src/app/blog/`)
2. Add `page.tsx` with your component
3. Add route to `Navbar.tsx` navigation links
4. Add route to `next-sitemap.config.js` `additionalPaths`
5. Add JSON-LD schema entry in `lib/jsonld.ts`

### Adding a New Component

1. Create file in appropriate `src/components/` sub-directory
2. Use existing design tokens from `globals.css` (e.g., `--space-md`, `--text-heading`)
3. Use existing utility classes (`.glass-card`, `.gradient-text`, `.btn-primary`)
4. Export as default for dynamic import compatibility
